OVERVIEW

Turning programming lessons into a clear digital experience.

Code With Ivana is a personal project created as a website for personalized programming lessons and coding support.

The website presents available lessons, learning options, pricing and information about the learning experience in one organized digital space.

The project combines a professional visual identity with practical features designed to make it easy for potential students to understand the offer and get in touch.

THE CHALLENGE

Presenting educational services in a clear and approachable way.

A website for personalized programming lessons needs to communicate both the educational offer and the personality behind the service.

The challenge was to organize information about lessons, pricing, target students and the learning process without making the website feel overwhelming.

The final structure uses clear sections, concise content and direct contact options to guide visitors through the available learning opportunities.
